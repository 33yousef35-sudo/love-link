# LOVE LINK

مشروع React + Vite باللغة العربية (RTL).

## التشغيل على الكمبيوتر
1. ثبّت Node.js.
2. افتح مجلد المشروع في الطرفية.
3. نفّذ `npm install`
4. نفّذ `npm run dev`

## النشر على GitHub Pages
1. ارفع محتويات هذا المشروع إلى مستودع `love-link`.
2. من إعدادات المستودع افتح Pages.
3. اختر GitHub Actions أو استخدم workflow مناسباً لبناء Vite.
4. إعداد `base` في `vite.config.js` مضبوط على `/love-link/`.

## ملاحظة مهمة عن حفظ الهدايا
النسخة الحالية تحفظ الهدايا في `localStorage` على نفس المتصفح والجهاز. رابط الهدية يفتح على جهاز آخر، لكن بيانات الهدية لن تكون موجودة هناك حتى نربط المشروع بقاعدة بيانات مثل Firebase ونضيف إعدادات مشروعك الحقيقية.
